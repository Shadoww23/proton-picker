Proton Picker does not include Proton, Steam, or any Valve software. It invokes

own terms and the licenses of installed Proton builds continue to apply.

## ProtonDB

The updater requests public compatibility summaries and report pages from
ProtonDB for installed game app IDs. Only the app ID is sent; GPU detection and
matching happen locally. No account, telemetry, or analytics are used. ProtonDB
content remains subject to ProtonDB's own terms and is not bundled with Proton
Picker.

## Fonts and network access

The dashboard uses locally installed system fonts with generic fallbacks and
does not load web fonts. The only automatic network requests are the optional
ProtonDB report lookups described above. No usage data is collected.
